TASK 3 — ENTERPRISE DOCUMENT LOADER (main feature)
================================================================================

Requirement
-----------
Implement a unified loader before the classification stage that:
  - Supports all formats: pdf, docx, pptx, txt, images
  - Extracts native text first
  - Extracts embedded images if needed
  - Runs OCR fallback if text < 30 chars
  - Returns unified (text, file_type) output

New File: parser/enterprise_loader.py
--------------------------------------
Public API:
  load_document_text(file_bytes: bytes, file_name: str) -> tuple[str, str]
  Returns (extracted_text, file_type)

Constants:
  MIN_NATIVE_CHARS = 30
  _IMAGE_SUFFIXES = {.png, .jpg, .jpeg, .gif, .bmp, .tiff, .tif, .webp}

Pipeline (internal):
  1. validate_file_size + ensure_supported_extension
  2. _normalise_file_type(extension) -> file_type token
       .jpg/.jpeg/.png/.tif/.tiff → "image"
       others → stripped extension (pdf, docx, pptx, txt, etc.)
  3. _extract_native_text(file_bytes, file_type)
       TXT_NATIVE_FILE_TYPES → delegates to office_loader.extract_text_from_office_file()
       "pdf"   → _extract_pdf_native_text() via pdfplumber
       "image" → returns "" (no native text layer)
  4. If len(native_text.strip()) < MIN_NATIVE_CHARS:
       _extract_ocr_text(file_bytes, file_type)
         "pdf"      → _render_pdf_pages() via pdf2image → Tesseract
         "docx/doc" → _extract_zip_images(prefix="word/media/") → Tesseract
         "pptx/ppt" → _extract_zip_images(prefix="ppt/media/") → Tesseract
         "txt"      → returns [] (no images possible)
         "image"    → _load_single_image() → Tesseract
       Append OCR text to native text
  5. Return combined text

OCR fallback helpers:
  _render_pdf_pages(file_bytes) — pdf2image/poppler, raises DocumentLoadingError
  _extract_zip_images(file_bytes, prefix) — unzip Office file, filter by suffix,
    convert to RGB PIL, return list; gracefully handles BadZipFile
  _load_single_image(file_bytes) — single PIL image list; returns [] on error
